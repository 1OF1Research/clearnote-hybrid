ClearNote Hybrid

Paste a note or a long document. Private notes are tidied on your device only — the text never leaves it, and the app refuses rather than sending them anywhere. Quick summaries run on-device when possible and fall back to the cloud. Long documents go to the cloud model for a deeper read, with an on-device fallback. All three run through Firebase AI Logic, and every result says where it actually ran.

  • Tidy privately — on-device only. If no on-device model is available, it refuses instead of sending your text to the cloud.
  • Quick summary — hybrid. On-device when Gemini Nano is available in Chrome, cloud fallback when it is not.
  • Deep read — cloud first. Structure, decisions and deadlines, and open questions from the stronger cloud model.
